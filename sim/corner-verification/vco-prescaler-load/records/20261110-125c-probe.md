# vco-prescaler-load 125 C convergence probe, 20261110 (issue #173)

**Result (simulated, not measured; local single-unit debug probes, no grid): no deck-level setting makes the 125 C units converge.
Swing (row 7) and startup at 125 C stay UNGRADED. Gate G2 for the loaded VCO stays open.** No batch re-run was submitted: no setting
changed, so a re-run would reproduce the errors in `20261110-stage{1,2}-corners.csv` (stage 1: 45 loaded 125 C units errored; stage 2: 18 loaded + 18
unloaded 125 C units errored; every one of them `analysis_aborted` + `timestep_too_small`, listed per unit in those CSVs, none dropped).

## Method

One `klt sim --backend local` unit at a time (host rule: single corner may run locally; no grid, no loop). Decks are the committed
`vco_unloaded.spice` / `vco_loaded.spice` from `make_requests.py` (pinned VCO lines unmodified); option variants appended `.options` /
`.nodeset` lines or changed the `.tran` card in a scratch copy, never in the repo deck. Unit: SLOW (mos_ss / cap_wcs / hbt_wcs), 2.970 V,
Vctrl 1.65 V, unless stated. Simulator: ngspice 46 locally (fleet is also 46, pin is 47: mismatch). `tran 1p 20n 0 2p` baseline.

## Findings

- **Failure is a temperature cliff, not a 125 C-only effect.** Unloaded, same corner: 27, 40, 50 C pass; 55, 58, 60, 70, 80, 85, 100, 110, 115,
  120, 125 C all `timestep_too_small`. The abort is at the **initial timepoint** of the transient, "trouble with xq1:npn13g2v_nx_vbic-instance"
  (the tail-pair HBT, VBIC model); the DC operating point is printed before the abort. TYP (mos_tt / cap_typ / hbt_typ, 3.3 V) at 125 C fails the same way.
- **Loaded, SLOW 2.970 V Vctrl 1.65 V**: 27 C converges (Vpp 0.521 V, startup proxy 158 ps; the 27 C grid already covers this), 125 C
  `timestep_too_small`.
- **Settings tried at 125 C, none converged** (all still `timestep_too_small`): `gmin=1e-10 reltol=1e-2`; `method=gear`; gear + `reltol=1e-2 gmin=1e-10 abstol=1e-10`;
  `tmax` 0.5 ps; `itl4=100 itl5=0 cshunt=1e-18`; `rshunt=1e9 vntol=1e-5 chgtol=1e-15 trtol=10`; `srcsteps=100 gminsteps=100 itl6=500 itl1=1000`
  (this one aborts earlier: gmin stepping failed, "Transient op failed"); `method=trap trtol=1` with 0.1 ps max step; tstep 1 fs; tight
  `reltol=1e-4 abstol=1e-14 vntol=1e-8 gear maxord=2 gmin=1e-14`; `uic` (skips the DC op: same abort); `.ic` replaced by `.nodeset`.
- Not isolated: whether the cause is the PDK's VBIC temperature scaling, ngspice 46's VBIC at T >= ~55 C, or the self-heating-free
  model's charge terms. A single-HBT bench was attempted and segfaulted ngspice 46 (my bench lacked the PDK's device setup), so no
  device-level conclusion is drawn.

## Status of the acceptance criteria

- 125 C units do not converge under any deck option tried; cause localised to the HBT (VBIC) transient start at T >= ~55 C, not resolved. The units stay `error`, never a pass.
- No tool gap established: the options were injectable through the deck, and klt reported the engine's diagnostics faithfully. Nothing filed on `2AMLogic/klayout-tools`.
- Swing (row 7 >= 0.40 Vpp) and startup at 125 C: **ungraded** (no waveform exists). Remaining route: a different simulator (the repo has Xyce on this host class)
  or a model-level fix, either a scope question for the owner of the VCO/PDK flow, not a deck tweak.
