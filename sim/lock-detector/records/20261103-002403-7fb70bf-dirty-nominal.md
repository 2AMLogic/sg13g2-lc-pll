## Method (stated next to every number below)

- **Stimulus**: REF is a fixed 50 MHz clock (T_ref = 20 ns, 100 ps edges). FB is a PWL source whose rising edge is delayed by phi relative to REF (phi > 0: FB lags, the pinned PFD pulses UP). The pinned PFD's UP/DN drive the pinned `lock_detector` unmodified.
- **Why VWIN is held**: the cell's integrator node `VWIN` (rhigh 0.5 um x 500 um into a 45 um x 45 um MIM cap) has a time constant of order 4 us, about 200 reference cycles; the closed-loop settle of one phase point costs hours of ngspice on the shared host (a 6 us probe took 8.4 minutes). The ERR/ERRD/WIDE chain upstream of `VWIN` does not depend on it. The bench therefore holds `VWIN` with an ideal source (`VH`, on the flattened node `xld.vwin`; the cell netlist is not edited) at each of a grid of voltages and integrates the current the cell sources into that node over one reference cycle: `I_net(V, phi)` = (integral of i(VH) over the window) / T_ref, positive = the cell charges VWIN. The closed-loop equilibrium of VWIN is the V where `I_net` = 0 (valid because VWIN's ripple is small against its time constant). This is a quasi-static balance model built from simulated currents, **not** a closed-loop LOCK transient; the closed-loop spot checks (separate records) test it.
- **Segments**: each (V, phi) point runs 3 reference cycles; cycles 0 and 1 settle the PFD/delay chain after the phase step, cycle 2 is measured. The window is [first input edge of the cycle - 1 ns, + T_ref).
- **Widths** ("UP", "DN", "ERR", "ERRD", "WIDE"): equivalent pulse width = integral of v(node) dt over the window / VDD (so a partial-swing pulse under-reads; the WIDE peak is given beside it). Overlap of UP and DN is the DN width for phi > 0 and the UP width for phi < 0.
- **twin**: ERR 50 % to ERRD 50 % at the largest phase error, rise and fall (the cell's `delaywin_hv` propagation delay; spec section 7 asks >= 2.5 ns).
- **Schmitt trips**: VWIN is ramped 3.3 -> 0 -> 3.3 V over 400 ns each way at phi = 0 with the cell's own `schmitt_hv`; the trip voltage is the VWIN value (linear ramp) when LOCK crosses VDD/2. `schmitt_hv` is inverting: LOCK rises as VWIN falls through the lower trip.
- **Thresholds**: for each of the two trip voltages, `I_net` at that VWIN is linearly interpolated from the held-V grid and the phi where it crosses zero is linearly interpolated between grid phase points. They are quasi-static equilibrium thresholds, resolved to the phi grid spacing (0.5 to 2 ns), not to the ps shown.
